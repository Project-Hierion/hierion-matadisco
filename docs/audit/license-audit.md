# LLMDataHub License Audit

## Purpose

This document tracks the license audit of datasets in the Project Hierion fork of LLMDataHub. Only datasets with explicit open licenses are eligible for publication to Matadisco.

## Audit Criteria

A dataset passes the audit if it has one of the following licenses:
- MIT
- Apache 2.0
- CC-BY (any version)
- BSD (any version)
- GPL (any version)

A dataset fails the audit if:
- No license is specified
- License is unclear or ambiguous
- License is restrictive or non-open
